What the 2024 returns would justify
BankRoTE 2024RoTE − CoEJustified P/TBV
RoTE = net profit / average tangible equity (equity attributable − AT1 − goodwill and intangibles). Justified P/TBV = (RoTE − g) / (CoE − g), with an assumed cost of equity of 10% and growth of 2% (the defaults of the Streamlit app). A bank that earns exactly its cost of equity is worth 1.0x tangible book value.

    About This Project
    An end-to-end financial data pipeline built from scratch, with no pre-cleaned datasets. The income statements and balance sheets come straight from the annual report PDFs of the four listed Greek banking groups; each year is taken from the latest report that contains it, so every comparison uses the same basis. The data goes through a Python ETL pipeline into SQLite and is queried here with sql.js, live in your browser.

    SQL — Window Function
    SELECT bank, year, nii,
      ROUND((nii - LAG(nii)
      OVER (PARTITION BY bank
      ORDER BY year)) * 100.0 /
      LAG(nii) OVER (...), 1)
      AS nii_yoy_pct
    FROM kpis
    Python — PDF Extraction
    with pdfplumber.open(pdf) as doc:
      lines = doc.pages[page - 1]
        .extract_text().splitlines()
    # find the statement line, keep the
    # two value columns and the page
    row = match(lines, "Net interest income")
    values = trailing_values(row, 2)
    SQL — ROE on Average Equity
    SELECT bank, year,
      ROUND(net_profit * 100.0 / ((equity +
        LAG(equity) OVER (PARTITION BY bank
        ORDER BY year)) / 2), 1) AS roe
    FROM kpis
    -- 2022 uses the end-2021 equity
    -- from the FY2022 reports
